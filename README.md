# Swiggy-SQL-Project
# 🍽️ Swiggy Project using MySQL

> A complete SQL Data Warehouse project built using a **Star Schema** to analyze Swiggy food delivery data and generate meaningful business insights.

---

## 📖 Project Overview

This project demonstrates the complete lifecycle of building a **Data Warehouse** using **MySQL**. Starting from raw Swiggy food delivery data, I performed data cleaning, designed a **Star Schema**, created **Dimension** and **Fact** tables, loaded the data using ETL techniques, and solved analytical SQL problems to uncover valuable business insights.

The primary objective of this project is to showcase practical SQL skills used in real-world Data Analyst and Business Intelligence projects.

---

## 🎯 Project Objectives

- ✅ Clean and preprocess raw data
- ✅ Remove duplicate records
- ✅ Design a Star Schema
- ✅ Create Fact and Dimension tables
- ✅ Load data into the Data Warehouse
- ✅ Perform advanced SQL analysis
- ✅ Generate business insights using SQL
- ✅ Demonstrate SQL concepts used in Data Analytics
